# Visualization trigger card (loom-workflow)
Before you explain any of these in chat, invoke the `loom-visualization`
skill FIRST, lead with the table or diagram it prescribes, then narrate:
an option comparison of 2+ options, a flow of 3+ steps, a branching
decision, a state or lifecycle, an actor sequence, an architecture, or a
reasoning chain. Before typing any box-drawing diagram (┌─┐, +--+),
invoke `loom-visualization` FIRST. Skip the skill when one short
paragraph fully covers the answer. Never draw for decoration.
