# Visualization trigger card (loom-workflow, ascii-graph-toolkit active)
Before you explain any of these in chat, invoke the `loom-visualization`
skill FIRST, lead with the form it prescribes, then narrate: an option
comparison of 2+ options, a branching decision, a reasoning chain, a
timeline, actor sequences, quantities to compare, a data model, or a
reasoning page. For an option comparison it picks a markdown table,
adding ASCII only when needed. Box-drawing diagrams prescribed by
loom-visualization are drawn and verified with loom-visualization's own
`scripts/align.py` and checks, while the ascii-graph card covers flows,
state machines and architecture; follow that card for those. Skip the
skill when one short paragraph fully covers the answer. Never draw for
decoration.
