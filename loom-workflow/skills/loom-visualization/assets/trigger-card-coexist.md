# Visualization trigger card (loom-workflow, ascii-graph-toolkit active)
Before you explain any of these in chat, invoke the `loom-visualization`
skill FIRST, lead with the form it prescribes, then narrate: an option
comparison of 2+ options (it picks a markdown table or Mermaid by client),
a branching decision, a reasoning chain, a timeline, quantities to
compare, a data model, or a reasoning page. Flows, state machines,
architecture, sequences and box-drawing/ASCII diagrams are covered by the
ascii-graph card; follow that card for them. Skip the skill when one
short paragraph fully covers the answer. Never draw for decoration.
