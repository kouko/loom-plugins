# What next

[loom-workflow](../../README.md) / whats-next

**English** | [日本語](README.ja.md) | [繁體中文](README.zh-TW.md)

Recommend one concrete next action for the current goal, with evidence,
the expected result, and alternatives only when they change the choice.
Ask naturally: “What should we work on next?” or invoke
`loom-workflow:whats-next` using your host's skill interface.

The agent may reconsider direction after a blocker or material new evidence.
A viable approved plan continues without repeated advice interruptions.
Completed goals may need no further work. Advice preserves existing permissions;
new scope and required consent stay with the action's original workflow.

Progress-only orientation belongs to [recap-state](../recap-state/README.md).
Synthetic output and description-selection samples do not establish
installed-host triggering or improvement over ordinary answers.
