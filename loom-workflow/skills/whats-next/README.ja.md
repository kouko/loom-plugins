# 次の一手

[loom-workflow](../../README.ja.md) / whats-next

[English](README.md) | **日本語** | [繁體中文](README.zh-TW.md)

現在の目標に合う次の行動を一つ推薦し、根拠と期待する結果を示します。
選択が変わる場合だけ代案を添えます。「次は何を優先すべき？」と尋ねるか、
ホストのスキル機能から `loom-workflow:whats-next` を呼び出せます。

行き詰まりや重要な新証拠があれば、エージェントも方向を見直せます。
有効な承認済み計画は、繰り返し選択を求めず続行します。
目標が完了していれば終了も推薦できます。推薦によって権限は増えません。
新しい範囲や必要な承認は、その行動を担当する元の手順で扱います。

進捗の整理だけなら [recap-state](../recap-state/README.ja.md) を使います。
合成入力への回答や説明文だけの選択試験は、インストール済みホストの
起動精度や通常回答に対する改善を証明しません。

実行時の指示：[SKILL.md](SKILL.md)。
