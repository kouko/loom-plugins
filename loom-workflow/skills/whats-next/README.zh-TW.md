# 下一步

[loom-workflow](../../README.zh-TW.md) / whats-next

[English](README.md) | [日本語](README.ja.md) | **繁體中文**

根據目前目標推薦一個具體下一步，說明依據與預期結果；只有會改變選擇時
才提供替代方案。可以自然詢問「接下來最值得做什麼？」，或透過 host 的
skill 介面呼叫 `loom-workflow:whats-next`。

遇到阻礙或重要新證據時，agent 也可重新判斷方向。已核准且仍可行的計畫
會繼續推進，不反覆要求選擇。目標完成時也可以建議停止。建議不增加授權；
新範圍與必要同意仍交回該行動原本的流程處理。

只想整理進度時使用 [recap-state](../recap-state/README.zh-TW.md)。
合成情境回答與僅憑描述的選擇測試，不能證明已安裝 host 的觸發可靠度，
也不能單獨證明比普通回答更好。
