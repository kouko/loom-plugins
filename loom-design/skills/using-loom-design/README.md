# using-loom-design

[Loom](https://github.com/kouko/loom-plugins/blob/main/README.md) / [loom-design](../../README.md) / using-loom-design

Select the appropriate product-definition skill without requiring you to know its name.

## When to use

Use this for a broad request about a product idea, specification, principles, visual system or architecture when the correct skill is unclear.

## What you get

A handoff to capture-intent, write-spec, product-principles, design-system or architecture-design. Each selected skill owns its output and confirmation requirements.

## How to use

Install the plugin as described in its [README](../../README.md), then ask
your coding agent to use the skill. For example:

```text
Use loom-design:using-loom-design to help define this product idea.
```

## Boundaries

- The router is optional; directly named skills remain callable.
- An idea without an intent is different from a confirmed intent that needs a spec.
- Implementation and delivery belong to loom-code; general workflow tools belong to loom-workflow.
