# Design research

[Loom](https://github.com/kouko/loom-plugins/blob/main/README.md) / [loom-design](https://github.com/kouko/loom-plugins/blob/main/loom-design/README.md) / design-research

Resolve evidence gaps that could change a decision about users, usage context,
outcome priorities, behavior alternatives or architecture. Use adequate existing
evidence directly, or choose the smallest useful investigation.

For example: “Do these conflicting workflow reports support changing the
navigation? Compare the relevant user outcomes before recommending an option.”

Research retains sources, applicable conditions, findings and uncertainty in a
question-scoped Markdown record. Follow-up recommendations update the matching
record; changed conditions preserve earlier decisions in a linked revalidation.
If saving is prohibited or unavailable, the result is an explicitly unsaved draft.

Findings return to the original task within its confirmed goals, user decisions
and authorization. Research does not ratify documents or advance user decision
points. Implementation capability questions remain engineering questions.
