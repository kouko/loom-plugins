# loom-workflow test files, second half: pin mapping (W1-06)

Scope: the prose candidates that `candidate-list.md` gives for `loom-workflow/tests/{distill-sessions,handoff,recap-state,scripts}/`. That is 62 rows in 9 files. Line numbers are from `candidate-list.md`, taken at `b13e646d`. The structural rows of these files classed "capitalized label" or "1-2 word" were re-checked too. Each is a field or section name (`Memory Item`, `Title`, `Summary numbers`, `Essential background`, `Pending work`, `2. Write`, `3. Apply`, `UserPromptSubmit`), and none hides a prose phrase. Two detector misses were judged with the rows next to them: the `(g)` class-method twin in `test_handoff_skill_md.py`, and the bad-example section scan in `test_seven_block_schema.py`.

Kind of change: "prune" drops the pin asserts and keeps the rest of the function. "delete" removes the function. "re-anchor" swaps the literal for an existing heading, a bold label or a path that the file already has. "keep" leaves the literal, with the reason given.

Rule 3 citations: nothing in `docs/loom/evidence/mechanisms.yaml`, `AGENTS.md`, `loom-code/tests/test_module_criteria_text.py` or the plugin tests cites a deleted function. `mechanisms.yaml` names two touched files as whole-file evals: `scripts/test_recap_state_compaction.py` (skill `recap-state`) and `scripts/test_visualization_card_hook.py` (hook `UserPromptSubmit::visualization-card`). Both files keep their other tests. The skill schemas quote the names `test_all_ten_blocks_and_five_principles_present` and `test_all_seven_blocks_and_five_principles_present`, and batch-3 records cite `test_l3_contract_defines_goal_grounded_natural_output` and `rule_polarity_errors`. All four names are kept. No deleted function ran a program.

"Lens" means `loom-code/skills/closing-review/references/lenses.md`. The skill lens scores a `SKILL.md`, a reference or an asset on the docs dimensions.
