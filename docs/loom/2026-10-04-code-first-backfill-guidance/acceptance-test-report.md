## 我不確定你要的

- **build 站本身的說法和第二個界線不一致，要一起處理嗎？** build 站寫的是「除非跳過 tdd，每個行為變更都先寫失敗的測試」，照字面讀，一旦跳過 tdd，連流程開始後新寫的程式碼也不用先寫測試。由實作 agent 動手時，新段落會勝出（它被告知以工程基準為準）；但如果你同時要求跳過實作 agent、由主 agent 自己寫，build 站沒有叫它去讀工程基準，它就看不到「流程開始後照常先寫測試」這條。這正是 intent 裡「agent 把自己新寫的程式碼當成先寫好的」那種重開條件會發生的地方。
- **「在 plan 記下先寫好的程式碼範圍」要不要指定寫在 plan 的哪一節？** 現在只說 plan 要記，沒說哪一節；不同 agent 可能寫在不同地方，reviewer 找起來會比較慢。
