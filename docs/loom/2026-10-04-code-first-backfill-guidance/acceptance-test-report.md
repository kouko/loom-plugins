## 我替你決定的事

- **怎麼確認外掛能載入** — 我沒有照 README 從 marketplace 安裝，而是在乾淨副本裡做外掛格式驗證，因為安裝會改動你本機已安裝的外掛設定。兩次都驗證通過。之後如果你想要真的安裝來試，要多花一次安裝與還原的時間。
- **新段落放在哪、怎麼釘住** — 實作時決定把新段落接在原本「舊程式碼補測試不算違規」那段後面，並沿用既有的文字比對測試。之後要搬位置，只需改一段文字和一個測試。
- **版號升 minor（3.30.0）** — 實作時判斷這是會改變 agent 寫程式做法的說明，所以升 minor 而不是 patch。只影響版號字串。
- **修正時順便改了 build 站的一句話** — 為了解決上次的不一致，修正時直接在 build 站那句話裡寫明跳過 tdd 的範圍，而不是只靠工程基準。好處是自己動手寫程式的主 agent 也看得到；代價是這次變更除了工程基準，也動到 build 站的說明文字（只限定範圍，沒有新增步驟）。
- **「先寫好的範圍」記在哪** — 修正時選了跟跳過紀錄放在一起：plan 的風險一節，沒有 plan 時放 intent 的限制一節。之後要換位置，要改工程基準一句話和一個測試。
