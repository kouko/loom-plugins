# 修正外部審查授權判定
originator: kouko
kind: engineering
needs-design: no — 既有外部審查規格已定義可見行為，這次處理內部授權判定
status: confirmed 2026-10-10

## Problem
本機合成句子實驗顯示，Loom 的執行前檢查會擋住明確改口後的審查請求；若執行者欄位仍保留舊選擇，也可能放行已撤回或只是詢問的請求。模型在本次實驗中能正確判斷是否應執行，但目前沒有真實使用時 coding agent 判錯最後選擇或因此對外傳送資料的紀錄。

## Proposed outcome
Loom 依完整對話中的最後選擇決定是否啟動外部審查；執行前仍核對授權紀錄與審查範圍，避免缺漏或不一致的紀錄啟動外部動作。

## Acceptance
1. 使用者取消、暫緩或改選外部 coding agent 後，被排除的 agent 不會執行模型查詢、探測或審查。
2. 使用者明確改回或選定某個 coding agent 時，指定 agent 能承接原本的審查任務，不因請求中的早期拒絕或附帶說明而要求重複確認。
3. 最後選擇或審查範圍不明確，以及授權紀錄缺漏或不一致時，外部動作不會開始；有效授權仍須保留資料傳送告知及模型與 effort 限制。

## Constraints
- 只做本機修正；不推送或建立 PR。
- 未取得針對具體資料傳送的明確授權，不把程式碼或審查內容傳給外部 coding agent。
- 保留明確直接請求免第二次確認的既有決定。
- 只修改授權語意的判定與必要測試，保留執行前的紀錄及範圍核對。

## Out of scope
- 變更外部供應商帳戶、額度或模型自動切換規則。
- 擴大外部 CLI 的檔案讀取權限。
