# 前置驗證程式的計數歸屬

status: confirmed 2026-11-17
intent_confirmed_sha: b21d7827c68d641b0e3382ac4405afbb0275be24

## Problem
在接續前置工作的變更上，使用者遇到驗證程式數量超過上限而無法完成驗證；其中包含前次工作留下且未修改的程式，不能僅憑本次實際使用的數量判斷能否通過。既有 finance 紀錄顯示本次只宣告重用一個程式，卻被計為六個。

## Proposed outcome
驗證程式的數量能核實其前置歸屬，排除可證明屬於前次工作的未變程式，並持續計入本次產生或明確使用的程式。

## Acceptance
1. 有有效前置驗證證據、版本未變且本次未明確使用的程式，不重複計入本次驗證程式數量；既有「前置五個、本次一個」情況不再因計為六個而拒絕。
2. 本次明確重用或提供執行的前置程式仍計入本次數量，同一路徑在不同計數來源出現時只算一次。
3. 缺少有效前置證據或無法核實程式版本的情況，不能獲得前置排除；本次新增、複製或實質修改的驗證程式不能藉前置歸屬漏算。
4. 本次確實有六個驗證程式時仍被既有五個上限拒絕；普通測試不因本修正被納入專用驗證程式上限。
5. 排除前置計數不縮小原有審查範圍、不降低所需審查者人數、不增加自動省略步驟，完整套件測試仍涵蓋前置測試。
6. 既有審查與驗證證據維持原有狀態，不因本修正被改寫或當作本次通過證據。

## Constraints
- user-decided — 「好 先  只針對計數核實前置歸屬」。
- 保留預設五個驗證程式上限，不加入使用者提高上限的例外機制。
- 以可核實的既有證據與程式版本判斷歸屬，不接受 agent 自填的排除聲明取代證據。
- 保留原有審查範圍與回歸測試保護，不以全域縮小分支比較範圍解決計數問題。
- finance 工作維持暫停，保留其 NON_CONVERGENT 結果；不重跑舊 finalizer、不重置審查額度、不修改舊測試、concern 標記或 attestation。
- 本次依交接邊界僅在本機處理；不授權推送、建立 PR、合併、全域安裝、修改安裝快取、外部傳送專案內容或正式 vault 寫入。

## Out of scope
- 使用者核准額外驗證程式數量或跳過驗證的支援。
- 全域變更範圍、審查者人數或自動省略政策的重新設計。
- finance 功能交付、重啟既有審查及投資研究。
- marketplace、各 host 安裝快取與新 session 行為的更新驗證。
