## Problem
代理使用 Loom 工具時，部分長任務未能及時提供進度資訊，難以分辨仍在執行或需要處理問題；部分不相關的檔案仍經過可避免的檢查。審查資料交接還需要代理自行轉換格式，但新增轉換工具能否降低操作成本尚未證明。

## Proposed outcome
讓代理更及時掌握工具執行情況，減少不影響判定的額外檢查，並取得可重現的資料轉換方案評估，作為是否新增工具的依據。

## Acceptance
1. 本次改善的長任務在結束前能提供可觀察的進度，成功、失敗與等待資訊與實際執行情況一致；既有結果輸出與退出狀態仍可正確使用。
2. 不符合目標資格的檔案不再觸發可避免的測試收錄檢查；符合資格、無法確認資格及既有特殊情況的判定仍與既有規則一致。
3. 在前兩項改善後，以相同案例比較既有資料轉換方式與候選方式，保留實際操作、結果正確性、錯誤處理及新增成本，明確說明是否值得加入工具；未量測的效益不宣稱已成立。
4. 既有使用者授權、獨立審查、驗收與失敗阻擋條件保持不變；本次不以減少必要驗證來取得效率改善。

## Constraints
- 保留既有判定政策與安全邊界。
- 先改善進度輸出與不必要的檢查，再評估資料轉換工具。
- 區分局部測試結果與真實任務的整體時間、token 或成本效益。

## Out of scope
- 全面重寫 Python 工具、全站排程器或整體工具協定遷移。
- 模型分派政策及使用者決策點的變更。
- 未經評估即將新的資料轉換工具加入正式流程。
