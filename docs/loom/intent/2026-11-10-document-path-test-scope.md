## Problem
完整套件在目前專案位置出現可獨立重現的文件路徑測試失敗，維護者無法取得全數通過的結果。測試依賴安裝另回報漏洞，目前尚未確認其影響。

## Proposed outcome
文件路徑檢查能保留防止寫死個人路徑的保障，同時正確接受依安裝位置產生的執行命令；測試依賴漏洞有可追溯的影響判斷。

## Acceptance
1. 正確的文件交付指引與指向目前安裝位置的執行命令可通過路徑檢查。
2. 文件交付指引寫死個人路徑，或執行命令未指向目前安裝位置時，路徑檢查可拒絕錯誤內容。
3. 專案指定的隔離環境完整測試通過，略過項目與環境限制據實列明。
4. npm 回報的測試依賴漏洞有來源、適用條件、影響與未確定事項的證據紀錄。

## Constraints
- 保留現有執行期行為及動態安裝路徑。
- 不以刪除路徑檢查或將個人路徑加入允許清單消除失敗。
- 先分析漏洞，不直接更新依賴或執行強制自動修復。
- 保留既有未追蹤檔案與無關工作。

## Out of scope
- 新增整個插件的搬移目錄測試。
- 改動 Git 交付與主分支保護功能。
- 修復或升級 npm 依賴。
