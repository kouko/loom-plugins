## Problem
完整套件長期跳過六項歷史測試，原因包含舊版已過期、受測工具或衝突已移除，以及缺少遷移前的比較資料。這些項目持續出現在跳過總數中，讓維護者難以判斷目前仍有哪些有效驗證未執行。

## Proposed outcome
這六項歷史測試的保留價值與替代驗證清楚可查；現行套件執行仍有意義的檢查，不再因這六項已失去的前提而跳過，也不以刪除必要保障換取較少跳過項目。

## Acceptance
1. 六項歷史測試各自的移除、取代或保留處置皆有可核對的理由，仍適用的驗證責任有明確去向。
2. 保留或替代的檢查能在乾淨環境實際執行，不依賴已退役工具、固定舊版本或當前分支恰有特定歷史資料。
3. 既有版本一致性、模組收集與衝突防護、記憶庫遷移資料保留及失敗保護等仍適用的保障不因整理而喪失。
4. 完整套件通過，這六項既有原因不再造成跳過；若有其他合理跳過，能逐項說明而不計為通過。

## Constraints
- 保留所有既有 worktree。
- 此變更與已發佈的 help PR #150 分開交付，不修改其分支或既有驗證紀錄。
- 保留既有失敗與跳過事實，不將未執行的檢查宣稱為通過。

## Out of scope
- 產品、CLI、hook、授權政策及記憶管理工具的正式執行行為變更。
- 與這六項歷史測試無關的全面測試重構或平台支援擴充。
- help PR 的合併及已安裝 plugin 更新。
