# W2-01 — retire map runtime and intent binding

Date: 2026-11-16

## Removed capability and coverage

- Deleted the decision-map skill's 21 files: instructions/README, two reference
  documents and 17 runtime scripts. No replacement CLI, converter or migration.
- Deleted its dedicated 16-file test directory (6909 lines), including fixtures.
  Deliberately retired coverage: map store/init/progress, lifecycle validation,
  lock/transactions, fog/link checks, delivery binding/evidence/start-delivery,
  governance and intent binding, v3 migration and module-boundary checks.
- Removed `check_map_exists`, its private originator matcher and the command
  handler's import/call. The command handler is an unavoidable extra file in
  the same defect class: leaving it would prevent the checker from loading.
- Removed three map-existence-only intent tests and their two dedicated
  helpers. Added one real-checker test proving historical map metadata needs
  no map runtime and is not rewritten; it must still satisfy ordinary intent
  rules. Existing required-field, identifier, reason, recomputation and
  anti-bypass cases remain and are exercised by the full intent test module.
- Removed the optional map field from the intent schema and both byte-paired
  templates; removed its capture-intent originator guidance. Replaced the
  contract tool and count/install/legacy-consumer inventories with roadmap.
- No historical records were changed. Historical `docs/loom/maps/**` artifact
  classification remains; it does not advertise or execute map operations.
  Plugin release metadata and overview-guide refresh belong to W3-01.
