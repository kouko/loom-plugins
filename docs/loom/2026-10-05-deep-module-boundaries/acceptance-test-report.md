## 我替你決定的事

- **規則只寫在 plan 指示裡，不另寫進工程基本規範** — 寫 plan 的人照規則標入口，判準留給審查端；代價是偶爾可能多一輪修正。要改的話是在基本規範補一句。
- **四條審查規則改在既有的四列裡，不新增審查項目或檢查代號；20／50 行與三次的數字保留，只從「判定」改成「提示」** — 照你在範圍外的決定。要改數字本身要另開一次改動。
- **版號升 minor（3.34.0）而不是 patch** — 因為改的是站點指示。改回 patch 只影響版號字串。
- **把抓到「入口定義會繞圈」的那支對抗測試正式收進測試套件** — 依 repo 的測試位置規則放在既有測試資料夾。拿掉它代價只是少一道防護。
- **第 1 到第 4 條用全新的 LLM reviewer 來判，而不是我自己判** — 我知道答案，自己判會失準。這些是玩具範例、單獨套用規則列，不等於在真實改動上跑一整輪 closing review。
