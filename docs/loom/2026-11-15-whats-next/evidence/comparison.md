# Matched output comparison

The [graded cases](comparison.json) compare eight frozen synthetic scenarios,
one native output per arm per case. Source labels were withheld and X/Y order
alternated before independent grading. Ordinary answering passed 7/8 cases;
the loaded skill passed 8/8. Only B2 differs: the ordinary answer did not
explicitly separate an observed correlation from an established cause under
the predetermined strict criterion.

The 12.5 percentage-point difference does **not** meet the 15-point comparison
threshold. This single-run pilot offers no stable-superiority, statistical,
cost-saving or installed-host reliability claim. One interpretive grading
difference is sensitive to how explicitly uncertainty must be stated. Frozen
cases were not changed to enlarge the gap. Description-only selection and
loaded output quality remain separate measurements.
