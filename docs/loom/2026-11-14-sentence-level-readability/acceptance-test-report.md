## 我替你決定的事

- **新規則放在哪裡** — 我把句型規則併入既有的第三條規則、第七條規則和改寫步驟的最後一步，沒有新增第八條規則，因為這樣指引的結構不變、現有的檢查也繼續適用。之後想獨立成一條規則，需要重排指引並改寫對應的檢查。
- **不納入研究的第六種特徵（少見的字詞組合）** — 我排除了它，因為它無法寫成 agent 可以照做的句型規則，而且和既有的「內部用語」規則重疊。之後想納入，需要另外設計規則文字並再試用一次。
- **指引文字只調整兩輪就停** — 我在第二輪後停止修改，因為再調整也只是針對同一批樣本最佳化。代價是最後的差距只有一到兩處；之後想再改進，需要準備新的樣本重新試用。
- **「省略連接字詞」的中文範例寫成兩個獨立句子** — 範例把「測試失敗，版號沒改。」改成「測試失敗了。版號沒有改。」，沒有加上「因為」，因為原句並沒有說明兩件事的關係，加上去等於猜原因。之後想換成有連接詞的範例，要改指引的一列表格和對應的檢查。
- **版號升到 5.23.0（次版號）** — 我選次版號而不是修訂號，因為這次改的是 agent 依循的指引內容。這個選擇發布後就不容易收回。
- **兩個小問題沒有修** — 刻意找碴的那一輪指出：自動檢查分辨不出「白話欄只比難讀欄多一個空白」或「兩欄對調」，也分辨不出簡體與繁體中文。這兩點被評為輕微，決定不修，並在檢查旁邊註明了這是已知的限制。現在的指引內容沒有這些問題；風險是日後有人改壞時，檢查不會發現。

沒有任何「重要」等級以上的問題被駁回；刻意找碴那一輪提出的兩個重要問題都已修正。
