# loom-design contracts and grammar-invariant mapping (W1-05)

Replacement for every pin removed from `loom-design/tests/spec/test_capture_intent_contract.py`, `loom-design/tests/spec/test_write_spec_contract.py`, `loom-code/tests/test_acceptance_test_report_shape.py`, `loom-code/tests/test_lenses_deletion_first.py`, `loom-code/tests/test_reviewer_mechanical_evidence.py` and `loom-code/tests/test_write_plan_shape_text.py`. Lens dimensions come from `loom-code/skills/closing-review/references/lenses.md`. A `SKILL.md` or an agent contract is scored under the "Skill lens" (the five docs dimensions plus `user-judgment-leak` and `deletion-first`), and a reference file under "Docs — five dimensions, plus deletion-first". Checker rule ids were checked against `python3 loom-code/scripts/loom_checker.py --list-rules`. No cold read is cited. The 2026-09-02 cold reads under `docs/loom/2026-09-02-simple-loom-flow/` predate the rules these files pinned, so a row with no other replacement says review-only.

Each synthetic partner (a matcher self-test that only proves a pin can fail) went with its pins and is listed in the same row. In the four grammar-invariant files the grammar checks stay: field shapes, heading grammar, table columns, verdict vocabulary, placeholder shape and path pointers.
