## 2. What `check_mechanisms.py` requires of an eval pointer

`loom-code/scripts/check_mechanisms.py:385-418` (rule R4, doc at :29-35):
- The eval must be non-empty (:393). The `pending — <task>` form is accepted but always red, R4-pending (:395).
- `cold-read: <path>`: the only check is that `<path>` is a file (:397-400). Content, date and relevance are never read. **Pointing at any existing cold-read file passes.**
- A bare path, or the part before `::`, must exist (:404) and match `test_*.py` or `tests/*.sh` (`is_test_path`, :88-89, :141-142; checked at :406).
- A `::node` must have every segment `def`/`class`-defined in the file, else pytest `--collect-only` must list it (:146-162, called at :414). **Pointing at a different existing test function passes.** Deleting a function that an eval still names fails R4.

- **Coupling outside the checker:**
  - `test_dispatch_profile_contract.py:156-160` and `:181-185` assert the literal `eval:` strings for `review.atomic-claude-dispatch` and `dispatch-profile.relative-routing`, so moving either pointer reddens those tests.
