沒有改動你的既有圖檔；這次只在乾淨副本建立測試圖檔。正式使用時，工具會讀取並更新你在存放庫內的圖檔及其文字投影；舊圖檔能否沿用，取決於是否符合約定格式。本次沒有測試備份或復原流程。

## 我代你決定的事

- 共享工具放在跨站工具中；兩個站別只引用它。往後調整圖檔規則需更新共用工具。
- 以圖檔旁的文字投影記錄所選後端，預設 draw.io；換後端需重新產生對應圖檔。
- 圖檔使用未壓縮 XML，版面先用固定座標；產生的版面仍可能需要手調。
- 用最小 JSON 示範第二後端，暫不接入另一套正式繪圖軟體。
- 圖檔與投影放在變更目錄；檢查也涵蓋規格連結到其他位置的圖檔。
- 本次沒有收到被撤銷的重要以上審查發現。
