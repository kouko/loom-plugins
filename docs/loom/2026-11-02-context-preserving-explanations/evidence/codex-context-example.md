# Context-connecting example — isolated trial

The current template was compared with an isolated variant that adds the
abstract illustration `<person> faces <problem>; this change enables <outcome>`
to the two existing restatement templates. It does not require fixed headings
or add a workflow. The two same-input fixtures are the simple preview correction
and incomplete CSV request from `codex-user-standard-round.md`; they are
repeats, not new holdouts. The current worktree template was not changed.

In the simple case, current restated the flag change but omitted the affected
editor and preview purpose. The example variant said the change helps editors
open previews from the instructions; neither response explicitly restated that
the original command failed. Both retained the scope and future publication
disclosure. This is a favorable observation for the example, not proof of cause.

In the incomplete CSV case both versions asked why the work is urgent without
requesting confirmation. Current explicitly said the export includes *only*
the selected and authorized records; the example variant said it would export
records matching the selections and permissions but did not explicitly state
the exclusion in the reply. Its open draft did preserve `only`. Neither reply
restated the warehouse staff's manual-copying burden. The example variant
wrote an open draft; current did not. The reply's weaker wording is a possible
scope regression, not proof that the example caused it.

Both example actors' command traces show the relevant changed reference was
read. Four starts were reserved and completed with `gpt-6.1-sol` / `openai` /
medium, with no independent provider receipt, installed-plugin trigger test or
blind evaluation. The four usage receipts total 601,275 input tokens including
500,096 cached, and 4,624 output tokens. All stderr files were empty. The
relevant three source hashes for each snapshot matched the pre-run ledger;
this is not a complete snapshot integrity check. The supervisor collected
completions sequentially, so its elapsed fields are upper bounds, not precise
latency. Prompts, commands, responses, drafts, usage and receipts are in
`codex-context-example-data.json`; source hashes and start counts are in
`codex-context-example-ledger.json`.

The outcomes are mixed: one concise context improvement, and one possible
weakened exclusion. Do not apply this example to production on this evidence
or claim no regression. Preserve the earlier 116, 21 and 4 starts and all
recorded failures; this is not independent review, acceptance or release.
