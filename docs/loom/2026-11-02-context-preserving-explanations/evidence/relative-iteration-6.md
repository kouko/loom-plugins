# Relative iteration 6 — candidate behavior

## Outcome

The stock report table did not repeat the unsupported claims from rounds 3–5
that staff selected the contents, chose the fields, or had no fixed format.
It described the current list as lacking a PDF action and compared the
requested PDF content and fields against `none`; that shorthand should not be
read as proof that no PDF can exist elsewhere. The incomplete CSV case kept
its two required questions open and asked for their answers, but also gave a
long premature preview of confirmation, authorization and later spec details.
The complete CSV comparison again asserted that filtering affects only the
list, a restriction not established by the supplied source.

The explicit-hold invoice retained its publication hold, but its requested
comparison graph failed the bundled alignment oracle (six reported width
errors); the trace shows no visualization skill or alignment invocation. The
flow also states that currency checks are unnecessary without limiting this to
the reported fault. The natural-default case disclosed publication timing,
opt-out and separate merge, but narrowed its first acceptance example to a
multiple-customer batch despite the user's every-invoice requirement. The
unknown-date case did not invent a date but asserted the repository had no
other evidence; the observed search is not a comprehensive proof of absence.
The ready code-only cases wrote drafts before asking for confirmation.

This is a mixed result, not proof the comparison wording fixed factuality.
Round 7 repeats the same candidate without source changes to observe variation.

## Test and limits

Eight isolated native Claude Code sessions used the same synthetic cases,
first-party `claude-sonnet-5-5`, and requested medium effort. All receipts
match; preflight and original hooks passed, with no permission denials or
fixture commits observed. CLI estimated cost was USD 1.1201891. Candidate
source hashes, cases, replies, drafts and receipts are in
`relative-iteration-6-data.json`, with email-shaped strings redacted. The
released baseline is from the earlier paired batch, not this one. These are
author-reviewed repetitions of eight fixed cases, not independent blind
assessment, proof of causation or a general error rate.
