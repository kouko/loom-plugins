# Context iterations — round 4

A new report-title fixture explicitly requested an ASCII before/after graph
and imposed a continuing publication hold. Both current and example preserved
the hold, the export and existing-report boundaries, and variable numeric
results. Both used titled ASCII frames but their edges were misaligned: current
lines measured 33/34 columns, example 43/44. The example mentioned manual
correction and re-export later in its explanation; the current version did not.
The trial does not show that the example caused either difference.

Two configured `gpt-6.1-sol` / `openai` / medium sessions completed, without
an independent provider receipt or plugin-trigger test. Input was 237,580
tokens including 206,592 cached, and output 2,843. Raw events, prompts, drafts,
stderr and receipts are in `codex-ten-context-round-4-data.json`; counts and
snapshot hashes are in the ledger. This single comparison is not independent
acceptance or a general reliability or cost estimate.
