## 我替你決定的事

- **只重跑一次指定案例，其餘核對原始紀錄** — 避免重複付費；九次的輸入、回覆、草稿及執行紀錄均保留。
- **把改變需求的提案與錯誤事實分開** — 缺日期時提議改成「待確認」明說是另一種佔位文字，沒有冒充真正日期；仍是使用者未要求的替代方案。
- **把補答後確認與直接確認分開** — 匯出需求要求先回答缺少的資訊，再說「是」；不能據此判成允許缺資料直接確認，但五段格式仍不符合原要求。
- **分開處理原情境與補測** — 原情境要求只擷取需求，可被理解為限制整項工作；補測移除這項歧義後，沒有額外加上持續暫停發布的限制，但依然漏了必要的授權說明。
- **把需求草稿也列入內容正確性的判斷** — 兩位獨立複核者都指出草稿與實際文件不符；重新核對後同意這是錯誤內容，不能因為對話說對了就忽略。另一個「不會誤導讀者」的保證也沒有證據支持。
- **將其他未達標處另列** — 圖形、贅述及一般情境的授權說明仍需改善；這些問題與上述內容錯誤分開，不推論為實際擅自發布。
