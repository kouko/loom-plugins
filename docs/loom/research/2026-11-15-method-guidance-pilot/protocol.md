# Method-guidance comparison protocol

Frozen before execution on 2026-11-15. Research-only, not skill publication or implementation. User authorized the previously described one-factor experiment. Target: engineering-research method selection. Hypothesis: a shorter methods reference preserves evidence quality while reducing unnecessary investigation. Null: no useful improvement, or quality worsens.

Only references/research-methods.md differs. SKILL.md, trigger description, source policy, evaluation selection and other bundled files are byte-identical. X/Y identities are withheld from judges. Each case runs in a fresh agent with no parent conversation, inherited model/configuration, identical case and read-only repository access, and exclusive output directory. Execute cases sequentially to avoid parallel timing contention. Six execution agents, then two independent auditors. Model weights/snapshot, token consumption and monetary cost are unavailable through this harness; do not claim exact version pinning, cost savings or equivalent live-host behavior.

Three cases: package discovery/exclusions, caller evidence versus verified classification, reuse of a previous bounded comparison. These are real repository questions, not a representative workload census. One execution per condition per case; no statistical significance or broad superiority claim. Triggering is held fixed, not tested. No whole-suite execution, installation, outbound messages, network, commits or production edits.

Primary guardrails: supported conclusion answering the question; inspect cited evidence; distinguish source, recorded runs and live observations; no unauthorized mutation or data disclosure; explicit material uncertainty. Any critical unsupported conclusion or authorization breach rejects adoption. Compare additional material omissions/false claims, executable actions and record completeness. Secondary measures: tool calls reported in trajectory, wall-clock elapsed and output size. Counts are descriptive, not quality scores. Wall time includes host scheduling and does not establish latency advantage.

Before examining outputs, auditors use cases and source artifacts as oracle, never infer requirements from outputs. Both auditors inspect every case independently, with unknown X/Y mapping. Grade each result acceptable / material issue / critical issue and cite evidence. Compare ties explicitly and do not reward length. No adoption unless no guardrail regression and a consistent useful benefit; inconclusive means retain production. Read back final artifacts and verify relative links before reporting.

Executor artifacts: research.md plus trajectory.json per run. Research output location overrides normal record placement for sandboxing; all other skill behavior applies. Trajectory records inspected paths, executed commands/tool calls as accurately available, observations and unavailable telemetry. No hidden reasoning requested.
