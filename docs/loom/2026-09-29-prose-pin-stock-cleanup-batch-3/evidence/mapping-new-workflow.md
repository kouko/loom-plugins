# Newly flagged loom-workflow files: pin mapping (W1-05)

Defect class: a direct sentence pin. That is an assert that passes only while one literal sentence or phrase of runtime prose (a skill, agent or reference file) keeps its exact wording.

Where we searched: the six files in the "Bucket loom-workflow" table of `deletion-list.md`. Every row was applied as listed. Besides the listed literals, the rows also named sentence regexes and a `pinned_sentence_ok` call that the detector misses. Each was judged, and they were removed as pins. Three more detector misses were judged the same way: the two-word phrases next to listed pins in `test_loom_delegation.py` and `test_decision_map_intent_binding.py`, and four sentence needles in the `required` tuple of `test_seven_block_schema.py`. The two deleted functions and the two orphaned helper example tests are cited nowhere in `docs/loom/evidence/mechanisms.yaml`, `AGENTS.md` or `loom-code/tests/test_module_criteria_text.py`.

"Lens" means `loom-code/skills/closing-review/references/lenses.md`. The skill lens scores an agent contract or `SKILL.md` on the five docs dimensions. Every kept test named below exists after this edit.
