## 我替你做的決定

- **允許的類型是 feat、fix、docs、refactor、test、chore、ci 七種** — 跟 agent 寫 commit 時本來就遵守的類型清單對齊，這是實作上的選擇，不需要你決定。之後要增減，只要改那一段說明文字與它的測試。
- **「同一個類型」只要求分支前綴和 PR 標題一致**，中途每一小步的 commit 各自標類型 — 因為 PR 合併時會壓成主幹上的一個 commit，主幹上看到的就是 PR 標題的類型。如果你的意思是連中途每個 commit 都要同一類型，這裡就會不一樣，要改的是那一段說明文字。
- **這個工作區的分支改名為 `feat/2026-09-14-typed-branch-names`**，讓這次變更自己先用新格式；工作區資料夾名稱沒跟著改。
- **分支名保留完整的變更編號，而不是只留短標題** — 同一主題可能重開多個意圖，只留短標題會讓一個分支對到好幾份文件資料夾。
- **審查站沒有交給我任何被駁回、嚴重度在 important 以上的意見**，這一項沒有可列的內容。
