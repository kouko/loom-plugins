## 我替你決定的事

- **第 1、2 條用全新的 LLM reviewer 來審，而不是我自己判** — 我派了只拿到規則表和被審檔案的 reviewer，因為我知道哪些測試是壞的，自己判會失準。改回自己判的代價是結果較不可信。
- **安裝那一步只做了驗證、沒真的裝** — 照 README 的安裝方式會從 GitHub 裝已發布的版本，而且會動到你本機實際的安裝，所以我改用 plugin 驗證工具檢查這個分支的副本。真的安裝要等合併發布後才試得到。
- **第 4 條我自己跑了完整測試** — 平常這留給最後的收尾檢查，但這條驗收本身就是「完整測試全過」，派我來的指示也要我跑，所以跑了一次。
- **第 3 條的假想情境是我編的** — 「匯出檔用 CSV」那條決定是我寫進一份假計畫裡的，用來重現上一輪審查找到的漏洞；它不是任何真實改動的內容。
