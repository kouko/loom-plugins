## 我替你決定的事

- **第 1、2 條用全新的 LLM reviewer 來審，而不是我自己判** — 我派了兩位只拿到規則表和被審檔案的 reviewer，因為我知道哪些測試是壞的，自己判會失準。改回自己判的代價是結果較不可信。
