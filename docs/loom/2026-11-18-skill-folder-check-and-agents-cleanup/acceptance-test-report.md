## 我替你決定的事

- **被 git 忽略的巢狀資料夾不算違規** — 實作選擇只要未 commit 就放行，因為這些內容不會進入 repo。之後想改成也要擋，只需調整檢查，但本機產生的快取資料夾可能讓測試失敗。
- **審查細節改為指向現有來源** — `AGENTS.md` 不再自己列出審查鏡頭和人數，改指向鏡頭說明文件與計算人數的自動檢查工具，避免兩邊內容不一致。代價是讀者要多開一個地方才看得到細節。
- **這次不 bump plugin 版號** — 變更沒有動到任何 plugin 內容，已安裝的副本不受影響。若日後認為文件變更也要發版，需要另開變更。
- **把抓到問題的對抗測試留進常設測試** — 這樣之後每次變更都會跑到，代價是測試數量多了四個檔案。
- **巢狀 git repository 只回報資料夾本身** — 如果 skill 的子資料夾本身就是一個 git repository，檢查會失敗並指出該資料夾，但不會列出裡面的個別檔案。這仍然符合「指出路徑」，只是你要自己打開資料夾看內容。
