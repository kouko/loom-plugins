## 我替你決定的事

- **write-plan 那句的新說法** — 我們選了「logic beyond that entry's reach」，因為意思不變、字數一樣，又不含否定詞。之後想換說法，只要改一句並重跑測試。
- **新測試放的位置** — 對抗測試轉正後放在 loom-code 的測試資料夾，照 repo 的測試位置慣例。之後要搬，只是搬一個檔案。
- **句子在哪裡斷開** — 對抗測試發現「i.e.」「e.g.」「...」會讓句子提早斷開、藏在後面的否定被漏看；修正後只在下一個字是大寫開頭時才算新的一句。代價是「i.e. Never」這種大寫寫法仍會斷開而漏過，測試的說明裡已註明。之後要更嚴，就得改斷句規則。
