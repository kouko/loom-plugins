## 對你既有的資料做了什麼

只有一處：以前在 OpenCode 裡，loom 會把你每則訊息另存一份到系統暫存資料夾，好讓程式判斷語言；改動後不再寫入，但已經存下的舊檔案沒有刪除，留在原處（這台電腦上是 2 個檔、共 8 KB），系統清理暫存資料夾時會一併消失。其他你已有的檔案都沒有被讀取或改寫。

## 我替你決定的事

- **沒有實際開 OpenCode 與 Antigravity** — 這台電腦上這兩個指令一啟動就會先更新你已安裝的 plugin，而這次規定不能動已安裝的東西。所以我直接執行兩者的提醒程式、並跑它們的測試來確認。以後想看真實畫面，要在你自己的終端機開一次。
- **試的時候暫時停用已安裝的舊版 loom-code** — 只在那幾段測試對話裡用額外設定關掉，沒有改你的設定檔；不然舊版的提醒也會一起出現，分不清是哪一版的效果。
- **用三種組合各試一輪** — 你平常的設定（預設 model）、較小的 haiku model、以及連 loom-workflow 的提醒卡都關掉的版本；因為 loom-workflow 的提醒卡本身也寫著「用使用者的語言回覆」，關掉它才看得出這句新提醒的作用。但你的全域 CLAUDE.md 也要求配合你的語言，它在每段對話裡都在，所以沒有一段能證明「只靠這句提醒」就夠。
- **只在指令列模式試** — 背景 agent 做完那一輪，在互動畫面裡的行為沒有試。
