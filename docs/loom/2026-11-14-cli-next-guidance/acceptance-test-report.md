- **既有介面相容** — 原本交付及準備流程的欄位不改名，避免這次新增建議迫使舊使用者一起改動。
- **版本發布** — 採次版本更新並同步各種套件描述與現行文件版本；這次試用沒有更新已安裝的外掛。
