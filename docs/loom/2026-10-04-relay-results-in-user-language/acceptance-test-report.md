## 我替你決定的事

- **用哪些時機觸發提醒** — 實作時接了「壓縮後接續、resume、skill 或 subagent 回來」；第一次驗收發現背景 subagent 做完的那一輪沒有提醒，修正時再加上「每一輪開始時」這個時機。「subagent 結束」那個時機仍然沒接，因為背景 agent 做完的那一輪已經由新時機涵蓋。
- **提醒現在每一輪都會出現** — 為了涵蓋背景 agent 做完的那一輪，用的是「每一輪開始時」這個時機，所以中文或日文對話裡，你每傳一則訊息，提醒也會跟著出現一次，不只在背景 agent 做完時。之後若覺得太頻繁，就是把這個時機從觸發清單拿掉。
- **測試怎麼裝 plugin** — 我沒有照說明重新安裝 plugin（那會改到你已安裝的版本），改成每段測試對話臨時載入乾淨副本。效果相同，只是沒有實際跑過安裝指令。

## 我不確定你要不要的事

- **簡體中文對話偶爾被帶成繁體。** 提醒本身是用繁體字寫的。修正後它每一輪都出現，我用簡體中文開了 8 段兩輪對話，有 1 段的第二輪回覆變成繁體；不載入這次的變更時試了 3 段，都維持簡體。次數太少，分不出是提醒造成的還是偶然。要不要再多試幾次，或把提醒改成不帶簡繁傾向的寫法？
- **中文裡夾很多英文術語時，提醒不會出現。** 這是語言判斷原本的規則，不是這次改壞的。主導這次變更的 agent 選擇不把它放進這次變更：改這條規則會影響其他共用同一個語言判斷的 hook。這次重跑我自己也碰到一次：我請它派背景 agent 的那句中文夾了很多英文名稱，整段對話都沒有出現提醒。要這次一起修，還是另開一個變更？
- **中文、日文以外的語言（英文、韓文等）仍然沒有提醒。** 主導這次變更的 agent 沒有處理，因為沒有任何一條驗收條件要求。這樣可以嗎？
- **還沒涵蓋的時機。** Codex 沒有語言提醒；OpenCode 只有載入 skill 後的提醒，這次新增的時機都沒有接上；一段對話的第一則訊息不會有提醒，從第二則開始才有；背景 agent 做完那一輪我只在非互動模式試過，互動模式沒試。
