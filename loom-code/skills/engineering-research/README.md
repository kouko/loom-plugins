# Engineering research

[Loom](https://github.com/kouko/loom-plugins/blob/main/README.md) / [loom-code](../../README.md) / engineering-research

Resolve factual uncertainties that could change an engineering decision,
within a Loom task or a standalone discussion. Research can include a small
version check, source inspection, a comparison or a bounded experiment.

For example: “Does the installed adapter support our required retry behavior?
Check the implementation before we choose the integration.”

Each independently answerable question gets a Markdown research record with
sources, applicable conditions, findings and remaining uncertainty. When saving
is unavailable or prohibited, the result is an explicitly unsaved draft.

Research stays optional and preserves the original task's authorization.
It does not replace implementation review or prove runtime behavior from
documentation alone. Long-term Obsidian preservation requires explicit
destination and scope consent; finding a Vault grants no write permission.
